# stunting-detection-device
An IoT device for early detection of stunting in infants and children.

---

## 📌 Overview

This device measures a child's weight, height, and body dimensions, then calculates stunting and malnutrition risk using WHO growth standards. Data is saved locally to an SD card and sent to a cloud server for further analysis.

**The problem it solves:**
Early detection of stunting is critical for child health. In remote areas, access to healthcare professionals is limited. This device allows community health workers to screen children quickly and accurately.
