# stunting-detection-device
An IoT device for early detection of stunting in infants and children.

---

## 📌 Overview

This device measures a child's weight, height, and body dimensions, then calculates stunting and malnutrition risk using WHO growth standards. Data is saved locally to an SD card and sent to a cloud server for further analysis.

**The problem it solves:**
Early detection of stunting is critical for child health. In remote areas, access to healthcare professionals is limited. This device allows community health workers to screen children quickly and accurately.

---
### 🛠️ The Story Behind This Project

This device was originally a research project for Universitas Indonesia (UI). The goal was to create a device for early detection of stunting in infants.

**The problem:** The project was stuck for 3 months. The team had abandoned it. It kept malfunctioning—the wiring was a mess, and the battery charging system had leakage issues.

**The solution:** I was brought in to fix it. With only 3 working days, I:
- Diagnosed the hardware issues (messy wiring, power leakage)
- Rebuilt the system on an Arduino Mega Terminal Shield (no time for a custom PCB)
- Fixed the sensor readings
- Made the device robust and reliable

**The result:** The device worked perfectly. The project was completed. I was paid 3 million IDR.

**Why this matters:** This project shows that I can:
- Troubleshoot complex hardware issues quickly
- Work under extreme time pressure
- Deliver working solutions when others have given up
- Adapt to constraints (no PCB, tight timeline)
